# SSIS BUILD — Web Starter

A simple starting point for web projects in **SSIS BUILD**.

You do not need to understand everything before you begin. Change something, test it, and see what happens.

## Files

- `index.html` — the content and structure
- `style.css` — how the page looks
- `script.js` — what the page does

## Start here

1. Change the title and text in `index.html`.
2. Change the appearance in `style.css`.
3. Add some behaviour in `script.js`.
4. Open the page and test it.
5. Commit your changes.

## The rule

> Start with the smallest version that works.

Build that first. Improve it afterwards.

## Ideas

You could turn this starter into:

- a school utility
- a game
- a quiz
- a mathematical applet
- an interactive story
- a data visualisation
- a portfolio
- an information site
- something completely different

## Using AI

AI tools are welcome for brainstorming, explaining, debugging and generating code.

But your team is responsible for understanding, testing and publishing what it creates.
